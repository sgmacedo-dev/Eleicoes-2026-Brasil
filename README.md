# Eleições 2026 Brasil

Portal estático, sem framework, preparado para GitHub Pages.

## Antes da publicação
- Substitua `SEU-DOMINIO-AQUI` em `robots.txt` e `sitemap.xml`.
- Valide candidatos, números, partidos, chapas, pesquisas e situação jurídica no TSE.
- Preencha `ads.txt` apenas com dados fornecidos pela plataforma de publicidade.
- Complete a política de privacidade conforme os serviços realmente usados.
- Conecte comentários, analytics e publicidade somente após configurar consentimento e privacidade.

## Arquitetura
HTML + CSS + JS puro. Os dados ficam separados em `dados/` para futura atualização automatizada por GitHub/n8n.
